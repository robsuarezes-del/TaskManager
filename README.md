# TaskManager

## Descripción del proyecto

TaskManager es una aplicación web de gestión de tareas desarrollada con HTML, CSS y JavaScript Vanilla (ES6+), como parte de la Actividad Integradora 2 de Programación.

El objetivo es facilitar la organización y el seguimiento de tareas mediante una interfaz interactiva, el consumo de una API REST y el almacenamiento local de datos en el navegador.

## Funcionalidades principales

- Crear, editar y eliminar tareas.
- Marcar tareas como completadas o pendientes.
- Filtrar tareas según su estado.
- Buscar tareas por título.
- Ordenar las tareas por fecha o prioridad.
- Mostrar métricas de tareas totales, pendientes y completadas.
- Obtener tareas desde la API JSONPlaceholder.
- Guardar y recuperar información mediante localStorage.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla (ES6+)
- Fetch API
- JSONPlaceholder
- Web Storage API (localStorage)

## Estructura del proyecto

- `index.html`: estructura principal de la aplicación.
- `styles.css`: estilos visuales de la interfaz.
- `main.js`: lógica principal e interacción con el DOM.
- `api.js`: funciones relacionadas con el consumo de la API.
- `storage.js`: funciones para guardar y recuperar los datos locales.
- `jsconfig.json`: configuración del proyecto JavaScript.

## Ejecución

Para utilizar la aplicación, abre el archivo `index.html` en un navegador web. La carga inicial de información desde la API requiere conexión a Internet. Los datos almacenados en localStorage pueden recuperarse desde el mismo navegador.

## Objetivo académico

Este proyecto permite aplicar los conocimientos de JavaScript, manipulación del DOM, consumo asíncrono de servicios REST y persistencia local de datos.
