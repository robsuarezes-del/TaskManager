# Declaración de uso de Inteligencia Artificial

## 1. Herramienta utilizada

Para el desarrollo de la aplicación web TaskManager se utilizó ChatGPT como herramienta de apoyo durante el proceso de aprendizaje y desarrollo. Su uso permitió consultar dudas técnicas, comprender conceptos de JavaScript y organizar la documentación del proyecto.

La herramienta se empleó como apoyo y las sugerencias generadas se revisaron según las necesidades de la aplicación.

## 2. Prompts utilizados

### Prompt 1: Estructura de la aplicación

“Explícame cómo organizar una aplicación web de gestión de tareas utilizando HTML, CSS y JavaScript, separando la estructura, los estilos, la lógica principal, las funciones de API y el almacenamiento local en archivos independientes”.

**Propósito:** comprender la organización de los archivos y la separación de responsabilidades dentro del proyecto.

### Prompt 2: Persistencia de datos

“Explícame cómo utilizar localStorage en JavaScript para guardar y recuperar tareas de una aplicación web, y cómo comprobar desde las herramientas de desarrollo del navegador que los datos se almacenan correctamente”.

**Propósito:** comprender la persistencia de la información y verificar los datos guardados en el navegador.

## 3. Revisión y ajustes manuales

Durante el desarrollo se organizaron los archivos del proyecto y se revisó su estructura para mantener separados el contenido HTML, los estilos CSS y las funciones JavaScript.

También se verificó el almacenamiento local mediante las herramientas de desarrollo del navegador, identificando la clave `taskmanager_tasks` y los registros almacenados en formato JSON.

Las sugerencias de la herramienta se utilizaron como referencia para comprender los procedimientos y documentar el trabajo. Los cambios y las comprobaciones deben corresponder a las acciones realmente realizadas durante el desarrollo.

## 4. Alcance y responsabilidad

La aplicación TaskManager es un proyecto académico. El uso de Inteligencia Artificial tuvo como finalidad apoyar el aprendizaje, resolver dudas técnicas y facilitar la documentación, sin sustituir la revisión del funcionamiento del proyecto.

## 5. Transparencia

Esta declaración documenta el uso de ChatGPT como herramienta de apoyo. Los prompts y las actividades descritas deben reflejar fielmente el proceso seguido durante el desarrollo de la aplicación.
